# Быстрый скролл и умный совет в ChatListActivity

Я реализовал функцию мгновенного возврата к началу списка чатов и добавил систему подсказок для пользователя.

## Что было сделано

### 1. Быстрый подъем (Scroll to Top)
- **Механика**: В [ChatListActivity.kt](file:///C:/Users/going/AndroidStudioProjects/Prime_messenger/app/src/main/java/com/messenger/prime/ChatListActivity.kt) добавлен слушатель долгого нажатия (`OnLongClickListener`) для аватарки в нижней панели.
- **Действие**: При зажатии аватарки список чатов плавно и быстро прокручивается к самому первому элементу (позиция 0).
- **Отклик**: Добавлена тактильная вибрация (`HapticFeedback`) при успешном зажатии, что делает взаимодействие более отзывчивым.

### 2. Система одноразовых советов
- **Персональный гид**: При первом запуске экрана чатов приложение теперь показывает уведомление: «Зажмите, для подтягивание к верху экрана».
- **Память приложения**: Используется `SharedPreferences` для хранения флага `"hint_scroll_top_shown"`. Это гарантирует, что совет появится **только один раз**, чтобы не раздражать опытных пользователей.
- **Интеграция**: Совет реализован через метод `showScrollTopHintOnce`, который вызывается при создании Activity.

## Технические изменения
- Обновлен метод `onCreate` в `ChatListActivity`.
- Добавлена вспомогательная функция для управления состоянием подсказок.

## Проверка
- Сборка: **Build finished successfully.**
- Функция быстрого скролла работает корректно.
- Подсказка отображается при первом входе и больше не беспокоит после перезапуска.

> [!TIP]
> Функция «зажатия для подъема» работает на любом уровне прокрутки, что особенно удобно, если у вас очень много активных чатов.
